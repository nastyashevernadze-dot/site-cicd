
# Site CI/CD

![Deploy static site](https://github.com/nastyashevernadze-dot/site-cicd/actions/workflows/deploy.yml/badge.svg)

## Описание проекта

Данный репозиторий содержит статический веб-сайт,
развёрнутый с использованием GitHub Pages.

Для автоматической публикации сайта используется
GitHub Actions.

## Используемые технологии

- HTML
- CSS
- GitHub Actions
- GitHub Pages

## Автоматическое развёртывание

При каждом изменении файлов и отправке изменений
в ветку main запускается автоматический workflow
Deploy static site.

Статус-бейдж отображает текущее состояние
последнего выполнения workflow.
